## 一、 核心文件与修改指南

所有内容均采用模块化、中心化配置，你只需要记住以下 3 个核心位置：

### 1. 管理好物与返佣链接
📁 **`src/data/affiliates.ts`**
这是全站商业化推荐的“单点真理数据库”。所有已上架好物（Binance、Wise、iFAST 等）均在此维护。

**添加新商品只需在数组中追加一项：**
```typescript
{
  slug: "product-slug",                 // 短链标识：访问地址为 /go/product-slug
  name: "商品或平台名称",
  taglineZh: "一句话中文卖点",
  taglineEn: "One-line English tagline",
  categoryZh: "数字金融与Web3",          // 分类（如：数字金融与Web3 / 生产力软件 / 硬件数码 / 生活好物）
  categoryEn: "Crypto & Finance",
  targetUrl: "https://your-affiliate-link.com/?ref=your_id", // 真实返佣推广链接
  badgeZh: "核心主力",                   // 徽标（选填）
  badgeEn: "Top Pick",
  rating: 4.9,                          // 评分（选填）
  priceZh: "新人专享优惠",               // 价格/优惠说明（选填）
  priceEn: "Exclusive Discounts",
  couponZh: "邀请码：XXXXX",             // 优惠券/邀请码（选填）
  couponEn: "Code: XXXXX",
  descriptionZh: "真实深度推荐理由与背景介绍...",
  descriptionEn: "Detailed review in English...",
  icon: "🪙",                           // Emoji 或图标
  featured: true,                       // 是否在首页展示
  posterImage: "/your-poster.png",      // 海报图片路径（存放在 public/ 目录下，选填）
}
```

## 二、 日常更新工作流（1 行命令自动上线）

由于网站已经与 GitHub 和 Cloudflare Pages 深度打通，**日常维护更新只需 2 步**：

1. **修改代码或数据**（在本地修改 `affiliates.ts` 或撰写文章）；
2. **在终端执行一键推送**：
   ```bash
   cd /Users/hdc/Desktop/工作/反重力/personal-affiliate-website
   git commit -am "feat: 更新好物推荐与内容"
   git push origin main
   ```

**Cloudflare 会在 30 秒内全自动拉取代码、打包并上线全网，你不需要登录任何后台手动上传！**

## 三、 绑定个性化独立域名（如 `hdc.com`）

1. 登录 [Cloudflare 控制台](https://dash.cloudflare.com/) ➡️ 进入 **Workers 和 Pages** ➡️ 点击 **`hdc-space`** 项目；
2. 切换到 **自定义域（Custom domains）** 选项卡，点击 **设置自定义域**；
3. 输入你自己购买的域名并确认，Cloudflare 会自动完成全球解析并签发免费 HTTPS 安全锁。
